# MoonAliza 0.7 development prerelease

Version **0.7.0**, development tag **v0.7.0-dev.1**. Windows x64 NSIS installer. This phase adds saved general chat without a folder and deliberate workspace attachment/switching, using the existing agent engine.

General chat supports Ask/Plan without project tools. Conversation privacy is explicit and intersects with project policy. Attaching a workspace creates a new conversation with only user-reviewed text; the original remains saved. Context recovery preserves the original privacy restriction, and refused runs preserve drafts. New folders are created through a native dialog and require trust before coding tools become available. Research tools remain a separate future stage.

## Data and release limits

Schema v2 migrates existing v1 conversations and retains message identities, events, FTS, operations and approvals. Regression tests use the original v1 DDL and populated history, including rollback on invalid foreign keys. Earlier app versions reject the upgraded database; migration is not a downgrade mechanism. Packaged tests use isolated application data and do not replace the user's installed app or qualify an in-place installer upgrade/uninstall.

This is an unsigned development release. Production signing and broader release/model qualification remain unfinished. General chat does not grant web browsing, project file access or commands. The external pinned Research Kit validator remains external and is not bundled.

Reproduce using [HANDOFF.md](../../HANDOFF.md), then `npm run package:win` and all desktop tests with `MOONALIZA_TEST_EXECUTABLE` pointing at `release/win-unpacked/MoonAliza.exe`. The user reviews and merges the phase PR.
