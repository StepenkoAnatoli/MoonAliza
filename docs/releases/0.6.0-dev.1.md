# MoonAliza 0.6 development prerelease

Installer version: **0.6.0**. Intended GitHub tag: **v0.6.0-dev.1**. This is a development checkpoint of the full product, with an unsigned Windows x64 NSIS installer.

The release adds explicit privacy guidance, profile editing, bounded/retrievable tool outputs, persisted context estimates and provider usage, and manual context recovery. It includes the previously merged managed-model backend and portable research/plan handoff. Managed activation still requires genuine qualification and production trust inputs; those prerequisites are not fabricated or bypassed.

## Verification record

Verification is in progress. Final test counts, installer checksum and release links will be recorded before publication. The prior installed 0.5 app is not automatically replaced by building this package.

## Reproduce

Use the Windows commands in [HANDOFF.md](../../HANDOFF.md). Package with `npm run package:win`, then run all desktop workflows against `release/win-unpacked/MoonAliza.exe` by setting `MOONALIZA_TEST_EXECUTABLE` for `npm run test:e2e`. Packaged application checks are distinct from installer installation/uninstallation and from general model-quality qualification.

Production signing and broad release qualification remain unfinished. Installer binaries belong in [GitHub Releases](https://github.com/StepenkoAnatoli/MoonAliza/releases), with a SHA-256 file and source revision; source code, plans, captured research and handoff documentation belong in Git.
