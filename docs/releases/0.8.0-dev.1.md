# MoonAliza 0.8 development prerelease

Version 0.8.0, tag v0.8.0-dev.1, Windows x64 NSIS installer. Public GitHub repository URLs now work in General and project chat without a token. The reader lists directories and reads bounded UTF-8 files, with commit-specific source URLs. This release also fixes local root-directory aliases and misleading generic permission errors.

Use a tool-capable model profile, paste a public GitHub repository URL and ask MoonAliza to read its README or source. No folder is required for public reads. Editing and commands still require an attached trusted local folder. Private authentication, general website browsing and cloning remain unsupported.

Local verification passed 511 tests across 37 files in 279.10 seconds, typecheck, lint, native/app build, Electron/SQLite runtime and all eight source desktop workflows (2.3 minutes). A live unauthenticated request read the real public MoonAliza root and README at 146ba4e52a48baf7e843c6d197ce42c8ebb1c9c7. The desktop workflow verifies main-owned reads and saved conversation restart with controlled API responses. Packaged verification and exact-head CI results are recorded in the phase PR and the release verification.json.

The [development release](https://github.com/StepenkoAnatoli/MoonAliza/releases/tag/v0.8.0-dev.1) carries MoonAliza-Setup-0.8.0.exe, SHA256SUMS.txt and verification.json identifying the exact source commit, installer hash, payload hashes and completed checks. Installers are release assets rather than source binaries.

The installer is unsigned. No database migration is added beyond 0.7's schema v2. Packaged tests use isolated app data; in-place upgrade/uninstall and broader production/model qualification are not claimed. Building/testing this version does not replace the user's installed app. See [GitHub reader scope and limits](../specification/github-url-reading.md), [the plan](../superpowers/plans/2026-10-01-github-url-reading.md) and [HANDOFF.md](../../HANDOFF.md).
