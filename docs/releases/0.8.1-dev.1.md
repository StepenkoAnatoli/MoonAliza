# MoonAliza 0.8.1 development prerelease

Version 0.8.1, tag v0.8.1-dev.1, Windows x64 NSIS installer. Public GitHub URLs work in General and project chat without a GitHub token. Paste a public repository URL and ask a tool-capable model to list files or read its README. Results include commit-specific source URLs. Local root-directory aliases and misleading generic permission errors are corrected too.

This version also preserves recovery refusal messages when Send creates a new conversation. A strengthened regression test failed on the old implementation because session loading erased the alert after a fast refusal. Navigation clears old errors explicitly; engine recovery requirements remain unchanged.

The original 0.8.0 source passed 511 tests, all eight source and packaged desktop workflows, and a real packaged run with Qwen/Qwen3-4B-Instruct-2507:nscale through Hugging Face. That model selected read_github and cited the actual MoonAliza README at commit 146ba4e52a48baf7e843c6d197ce42c8ebb1c9c7. Its PR and tag CI passed, while its branch CI exposed the recovery race above. The live model check is evidence for the unchanged reader, not a repeated 0.8.1 installer check.

Correction verification passed all 12 renderer tests, typecheck, lint, application build and three consecutive real Electron recovery/restart workflows (2.5 minutes). Final packaged checks and exact source/installer identities are recorded in [PR #14](https://github.com/StepenkoAnatoli/MoonAliza/pull/14) and the release verification.json. The [development release](https://github.com/StepenkoAnatoli/MoonAliza/releases/tag/v0.8.1-dev.1) carries MoonAliza-Setup-0.8.1.exe, SHA256SUMS.txt and verification.json. Installers are release assets rather than committed binaries.

The installer is unsigned. No database migration is added beyond 0.7's schema v2. Packaged tests use isolated app data; in-place upgrade/uninstall and broader production/model qualification are not claimed. Building/testing does not replace the user's installed app. Private GitHub authentication, arbitrary website browsing and cloning remain unsupported. Editing and commands require an attached trusted local folder. See [reader scope](../specification/github-url-reading.md), [the plan](../superpowers/plans/2026-10-01-github-url-reading.md) and [HANDOFF.md](../../HANDOFF.md).
