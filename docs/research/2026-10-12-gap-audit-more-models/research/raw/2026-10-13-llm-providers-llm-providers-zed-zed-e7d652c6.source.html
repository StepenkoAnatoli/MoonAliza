LLM Providers

Use this page to choose which models power the Zed Agent and other Zed-owned AI features, including Inline Assistant, Git commit generation, thread summaries, and similar model-backed features.

Model access paths do not configure External Agents or Terminal Threads. External Agents and Terminal Threads usually own their own model access, auth, and configuration.

Choose a Model Access Path

Model access pathBest whenSource of truth
Use Zed-Hosted ModelsYou want models billed through ZedAccount & Billing > Zed-Hosted Models
Use API AccessYou have provider API access, credits, or usage billingUse API Access
Use an Existing SubscriptionYou already pay for ChatGPT, Claude, Copilot, or another subscriptionUse an Existing Subscription
Use a GatewayYou route through OpenRouter, Bedrock, Vercel, or a similar platformUse a Gateway
Use a Local ModelYou run models locally or self-hostedUse a Local Model

Use the setup pages for provider-specific details. See Agents for the difference between the Zed Agent, External Agents, and Terminal Threads.

Edit Prediction

Edit Prediction has its own provider setup under edit_predictions. LLM providers on this page apply to model-backed Zed AI features such as Zed Agent, Inline Assistant, Git commit generation, and thread summaries.
