# Discovery Contract - Is Selenic free to use as the product name of a Windows desktop AI coding assistant (formerly MoonAliza/Moonzila): software products and companies named Selenic; Selenic open-source projects and package names and web domains; Selenic registered trademarks in software and developer tools

Started 2026-10-12. This file is the definition of "enough information to build".
`node "$HOME/.agents/research-kit/bin/preflight.mjs"` reads it and blocks the build until every unknown
below is either `CLOSED` with evidence or `KNOWN-UNKNOWN` with a verification step.

## Build intent

The Windows desktop AI coding assistant developed in this repository (an Electron app, repository Moonzila, earlier product name MoonAliza) needs a product name, and the operator proposes **Selenic**, saying a web search showed it to be unique. Nothing is built from this project: it is a naming decision. Done means a reader who has never seen the project can tell, from captured owner pages and registers, (a) whether any software product, developer tool or company already trades as Selenic and whether that use is current; (b) whether a trademark containing SELENIC is filed or registered, by whom, for which goods and services, and in which register; (c) whether the package and account names `selenic` on npm, PyPI and GitHub are taken; (d) whether selenic.com, selenic.dev, selenic.app and selenic.ai are registered; (e) whether a Windows app named Selenic is listed in the Microsoft Store; (f) what the word means; and, for every register that could not be read, the exact manual search to run. The verdict is a risk call (free, usable with caution, or conflicting), not legal advice.
