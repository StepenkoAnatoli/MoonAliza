## Coverage notes (per dimension)

- D-1 (access): the package registries, GitHub, the domain registries (RDAP) and the Microsoft Store answer public JSON endpoints, the USPTO's TSDR status page and the businesses' own sites are plain HTML (E-03, E-09 to E-12, E-21, E-06 to E-08, E-16, E-01, E-02, E-05, E-19, E-20). TMview and the WIPO Global Brand Database are JavaScript applications that this transport could not read (U-03, E-18), and the USPTO's trademark search rendered without running the query (U-12, E-22), and an RDAP 404 is kept only as a ledger fail entry (U-09).
- D-4 (legality of the intended use): the use is a product name, so legality is trademark conflict. A live US registration, PARASOFT SELENIC, covers downloadable software for detecting and correcting programming errors (E-03), and the same owner sells a current AI-marketed developer tool named Selenic (E-01). EU and WIPO filings are KNOWN-UNKNOWN (U-03).
- D-6 (freshness): every record is dated 2026-10-12; registrations and domain holdings change, and the brief says what to re-check before any filing or launch.
- D-8 (platform): the Microsoft Store's US search counted no match for selenic and listed no app named Selenic (E-16, U-07); its response is internally inconsistent, so whether any listing exists is U-11, with a day-one step.
- D-9 (obtainability): the verdict could be produced from captured registers and owner pages for the US mark, the businesses using the name, the package registries, GitHub, three domains and the Store's US search; it could not be produced for EUIPO and WIPO (U-03), a primary USPTO search with variants (U-12), selenic.app (U-09), a Store listing in any market (U-11) or the Mercurial company question (U-10), which carry day-one steps.
- S-1 to S-7: closed or labelled by U-01 to U-12 as recorded in research/DISCOVERY.md.
- D-2, D-3, D-5, D-7: dismissed with the reasons in the table.
