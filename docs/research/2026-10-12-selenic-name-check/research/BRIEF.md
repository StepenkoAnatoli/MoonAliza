## Decision

**Verdict: Selenic is not free to use as the name of an AI coding assistant. It conflicts.** Confidence is high for three things, each resting on the registers' and owners' own pages captured on 2026-10-12: the existence, status and goods of US Reg. No. 8222950, the five current third-party uses of the name, and the taken package, account and domain names. Whether SELENIC alone would conflict with that registration is a legal judgement, and this record does not make it. Three registers could not be read: the EU and WIPO registers (U-03), the USPTO's own search including variants (U-12), and Store listings beyond one inconsistent US search (U-11).

Why, in order of weight:

1. **A live US registration covers overlapping goods.** PARASOFT SELENIC is US Reg. No. 8222950, registered 2026-04-21 and owned by Parasoft Corporation. It covers Class 9: downloadable software for detecting and correcting computer programming errors (E-03). An AI coding assistant's job includes detecting and correcting programming errors, so the goods description reads on this product. The registered mark is the two words PARASOFT SELENIC, with PARASOFT the house name and SELENIC the product name: Parasoft's own page also calls the product Selenic alone, as in "Selenic's self-healing capability" (E-01). Whether that makes SELENIC alone confusingly similar is a trademark attorney's call. The overlap of goods is plain from the record.
2. **The same owner sells a current AI developer tool called Selenic** (E-01). It generates Java Selenium test code and uses AI to detect and fix broken tests, and Parasoft publishes its own Maven plugin for it on GitHub (E-12). The market already reads Selenic as a Parasoft developer-tools brand.
3. **A second business already sells AI software as Selenic.** Selenic, at selenic.ai, builds custom AI agents, automations and apps for clients, and is taking on projects (E-19). Three more businesses trade under the name: Selenic Access, software development and system integration at selenic.io (E-20); Selenic Systems Ltd, a UK mobile-app maker (E-02); and selenic consulting at selenic.com (E-05).
4. **The practical names are taken.** These include github.com/selenic, a user account (E-11), PyPI selenic (E-10), the npm @selenic scope (E-09), and selenic.com, selenic.dev and selenic.ai (E-06 to E-08). Still open: the unscoped npm name selenic (E-09) and, probably, selenic.app (U-09). The Store's US search counted no app named Selenic (E-16), but that absence is not proven (U-11).
5. **The word is a dictionary word.** It is chemistry by definition and attested in a lunar sense (E-14). So a mark would rest on an existing word, not a coined one, even though the word is arbitrary for software. The lunar sense fits the rename from MoonAliza. It does not make the name free.
