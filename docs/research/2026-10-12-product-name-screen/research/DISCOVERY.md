# Discovery Contract - Product-name screen for a Windows desktop AI coding assistant: is there an obvious conflict for Moonwright, Lunarch, Perilune, Selunara or Tidewright as the name of an AI coding assistant or developer software (US trademark index, web search, GitHub, .com domain)

## Build intent

The Windows desktop AI coding assistant developed in this repository (an Electron app, repository Moonzila, earlier product name MoonAliza) needs a product name. The sibling project `docs/research/2026-10-12-selenic-name-check` found that Selenic conflicts (a live US registration, PARASOFT SELENIC, Class 9, for software that detects and corrects programming errors, and a current AI developer tool sold as Selenic). Five replacement candidates are now screened: **Moonwright, Lunarch, Perilune, Selunara and Tidewright**. Nothing is built from this project: it is a naming screen, the step before a full check of the name chosen. Done means a reader who has never seen the project can tell, for each of the five names and from captured pages dated 2026-10-12: (a) whether Justia's index of USPTO filings lists a mark for the exact name, and if so its owner, class and status (from the USPTO's TSDR record where the index points to a live mark in software classes); (b) whether one web search for the name with software or AI shows a current software or AI product or company using it; (c) which GitHub repository matching the name has the most stars; (d) whether the .com is registered, since when and through whom; and (e) a verdict per name - clear so far, caution, or conflict - with the evidence row that decides it, and a ranking. Every absence rests on a captured results page, and the brief says what each absence does and does not prove. The verdict is a screen, not a clearance and not legal advice.

## Already decided

Locked decisions for this project. Do not revisit these without the human.

- The product is a Windows desktop AI coding assistant (Electron), in the Moonzila repository, earlier named MoonAliza; Selenic was rejected by the sibling project `docs/research/2026-10-12-selenic-name-check`.
- This is a screen, not a clearance: one unknown per name, "is there an obvious conflict for an AI coding assistant or developer software?", from four sources per name - Justia's index of USPTO filings for the exact name (a TSDR record when the index points to a live mark in software classes), one web search for the name with software or AI, GitHub's repository search sorted by stars, and the .com registry's RDAP record. A source is skipped for a name once earlier sources already show a clear conflict.
- Budget: at most 20 Firecrawl credits for the whole project including phase 0 (about 4 a name). Phase 0 ran as a dry run and spent nothing. `--fallback` is never passed.
- Not reached for, by design: the USPTO's own search with phonetic and look-alike variants and design marks, TMview/EUIPO and the WIPO Global Brand Database (the sibling project found these are JavaScript applications this transport could not read), package registries, the Microsoft Store and other TLDs. They belong to the full check of the name chosen, which the sibling project's plan files are the template for.
- Verdict scale per name: **conflict** (a live US mark for the exact name in software classes, or a current software or AI product trading under it), **caution** (a use or filing that is near but not on the field, a taken .com, or a mark whose class or status leaves doubt), **clear so far** (nothing found in the four sources). The verdict is a risk call from public records, not legal advice.
- How the scale's words are read (written 2026-10-12, after collection, when a review found that the first draft had scored Perilune against the scale's own words by narrowing conflict to developer tools - a rule written nowhere and not applied to Tidewright; the scale above is unchanged, and this reading is applied to all five names alike). A **software or AI product** is any application, game, engine, service or AI model, in any field: conflict is not narrowed to developer tools. **Trading under it** means offered to the public under the name - its own site, a store, marketplace or download listing, or a company that sells under the name. A person's surname, a fictional character and a personal repository with no site of its own do not trade. **Current** means on offer on the capture date, or shown active in the last twelve months by a dated record. A software or AI use the captures do not show to be current, and a product that is not software or AI (a website design template), is caution: near the field, not on it. Where a name turns on this reading, its row says which way it would go.
